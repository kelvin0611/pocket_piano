# 🐒 獼猴元素 — 放置建議 ＋ 出圖 Prompt

> 你女友成日話你似獼猴 → 呢個係**只屬於你哋兩個嘅 insider joke**，放入去一定會心微笑。
> 下面係我建議嘅位置（0 風險 → 最到肉），同埋要生成嘅圖。

---

## 一、放置建議（我會點做）

| 位置 | 做法 | 要唔要圖 | 笑點 |
|---|---|---|---|
| 🥇 **機殼貼紙** | 加一隻獼猴貼紙（同 Piano 貼紙排埋） | 要（1 張） | 你女友一開機就見到，似你嘅簽名 |
| 🥇 **夢境／生日會「真身」** | 傻豬傾到最後自爆：**「其實…我女朋友話我似獼猴。」** → 佢個 sprite 變成獼猴 2 秒 → 變返 | 要（動作圖） | 全個遊戲最到肉嘅位，佢一定會笑出聲 |
| 🥈 **村口樹上／招牌上嘅獼猴** | 一隻獼猴掛喺樹／招牌，行過會講串嘴對白 | 要（小圖） | 探索時嘅小驚喜 |
| 🥈 **Credits 加一行** | 「特別演出：獼猴（傻豬）」 | ❌ 唔使 | 免費笑點，睇到會心微笑 |
| 🥉 **開場封面角落** | 封面右下角有隻獼猴探頭出嚟 | 要（同上面共用） | 一開頭就種下伏筆 |

**我建議對白（可以直接用，想改就講）**
- 夢境傻豬：「{name}，其實我一直都冇同妳講一樣嘢。」
- 「我女朋友話我似獼猴。」（停 1 秒，換獼猴 sprite）
- 「…好啦，似係似。但係我係一隻**有型**嘅獼猴。」（變返豬）
- 村口樹上獼猴：「妳男朋友？佢成日爬樹㗎喎。」
- Credits：`特別演出　獼猴（傻豬）`
